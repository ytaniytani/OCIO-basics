## 色のきほん

**色空間 (color space)** — 色の「単位」の決め方 / 数字にどんな色を割り当てるかの約束。原色の位置・白の色・数値と明るさの関係、の3点セット。第2章

**色域 (gamut)** — 使える色の広さ / その色空間で表現できる色の範囲。色度図の三角形の大きさ。第2章

**白色点 (white point)** — 「白」をどの色にするか / D65 は昼の空の光に近い白。第2章

**原色 (primaries)** — 混ぜるもとの3色 / 赤・緑・青をそれぞれどこに置くか。第2章

**伝達関数 (transfer function)** — 数字の曲げ方 / 光の量と保存する数値の対応ルール。第3章

**ガンマ (gamma)** — 数字の曲げ方の一種 / いちばん単純な形の伝達関数。第3章

**リニア (linear)** — まっすぐ / 光の量と数値が比例している状態。第3章

**シーンリニア (scene-referred linear)** — 光の量そのもの / 現場にあった光の量に比例した数値。1.0 を超えてもよい。第3章

**ディスプレイ参照 (display-referred)** — 画面用に加工ずみ / 画面に出すことを前提にした数値。ふつう 0〜1。第3章

**中間グレー (middle grey)** — 当たった光の18%を返す灰色 / 18%グレーとも言う。写真・映像・CGで共通に使う基準の明るさ。光の量(0.0が真っ暗、1.0が基準の白)で 0.18。sRGB で保存すると数値 0.461、8bit なら 118。第3章

**反射率 (reflectance)** — 光を返す割合 / 当たった光のうち何%を返すかというものの性質。白い紙で80〜90%、18%グレーカードで18%、黒いビロードで1%くらい。100%のものは実在しない。第3章

**基準の白** — 光の量の目もりの 1.0 / 「当たった光をぜんぶ返す理想の白」を 1.0 と呼ぶという決めごと。実在の品物ではなく、上限でもない。自分で光るものは 1.0 をいくらでも超える。第3章

**ダイナミックレンジ** — 明るさの守備範囲 / 一番暗いところと一番明るいところの幅。第4章

**段 (stop / EV)** — 光の量の2倍きざみ / 1段上がると光が2倍、1段下がると半分。13段なら約1万倍。第4章

**白飛び (clipping)** — 真っ白でつぶれる / 記録できる上限を超えて情報が消えること。もどらない。第4章

**ビット深度 (bit depth)** — 数字のこまかさ / 8bit は真っ黒0から真っ白255までの256段階。10bit なら1024段階。第4章

**float(浮動小数点)** — 小数で持つ / 1.0 を超える明るさも記録できる。第4章

## 色空間の名前

**sRGB** — パソコンやスマホの標準 / いちばん普及している表示用の色空間。第2章

**Rec.709** — テレビの標準 / sRGB とほぼ同じ色域。伝達関数の扱いが少し違う。第2章

**Display P3** — 少し広い / 最近のスマホやMacの画面。赤と緑が sRGB より濃く出せる。第2章

**Rec.2020** — かなり広い / 4K/8K放送や HDR で使う。第2章

**ACES2065-1 (AP0)** — 保存と受け渡し用 / ACES のいちばん広い色空間。人の目に見えない色まで含む。第8章

**ACEScg (AP1)** — CGと合成の作業用 / リニアで扱いやすい。ACES で作業するときの主役。第8章

**ACEScc / ACEScct** — 色を調整するとき用 / 対数のカーブ。ACEScct は暗いところの操作感が従来機に近い。第8章

**Log** — 眠い灰色に見えるやつ / 広い明るさを少ないビットに詰め込む記録方式。カメラごとに種類がある。第6章

## OCIO

**OpenColorIO (OCIO)** — 色の翻訳係 / どの色空間からどの色空間へどう変換するかをまとめて、いろんなソフトに同じ答えを出させる仕組み。第6章

**config.ocio** — 変換のルールブック / OCIO の設定を書いた1つの YAML ファイル。第7章

**colorspaces** — 色空間の一覧 / config でどんな色空間を扱うかの定義。第7章

**roles** — 役割の割りあて / 「作業用はこれ」「表示用はこれ」と名前で決めておく仕組み。ソフトはこの名前で色空間を探す。第7章

**displays / views** — 表示先と見え方 / どの画面に、どの見た目で出すかの組み合わせ。第7章

**looks** — 味付けの登録 / config に書いておける調整。第7章・第9章

**環境変数 OCIO** — どの config を使うかの指定 / パソコンにパスを設定すると、対応ソフトがそろってその config を使う。第7章

**LUT (Look-Up Table)** — 変換の早見表 / 計算のかわりに表を引いて色を変える方法。`.cube` などのファイル。付録

## ACES

**ACES** — 映画業界の共通ルール / Academy Color Encoding System。どのカメラの絵も同じ場所に集めて作業するやり方。第8章

**入力変換 (Input Transform / IDT)** — 素材を共通の場所に翻訳 / カメラごとの絵を ACES の座標に持ってくる。第8章

**出力変換 (Output Transform)** — 見る機械に合わせて刷る / ACES のデータを、その画面で正しく見える形に変換する。ACES 1.x では RRT と ODT の2段だった。ACES 2.0 では1つにまとまった。第8章

**RRT (Reference Rendering Transform)** — 共通の見た目づくり(ACES 1.x) / どの出力にも共通でかかる仕上げ。第8章

**ODT (Output Device Transform)** — 出力機器ごとの調整(ACES 1.x) / RRT のあとで、画面ごとの違いを合わせる。第8章

**LMT (Look Modification Transform)** — 作品全体の味付け / 出力変換の前に入れる。第9章

**トーンマッピング (tone mapping)** — 広い明るさを画面に押し込む / 明るすぎる部分をなだらかに丸めて表示できる形にする。第8章

## グレーディング

**カラーグレーディング** — 色の味付け / 明るさと色みを整えて作品の雰囲気を作る作業。第9章

**カラーコレクション** — 色をそろえる / カットごとのばらつきを合わせる作業。グレーディングの前段。第9章

**CDL (ASC CDL)** — 調整のかんたんな共通形式 / slope・offset・power・saturation の4つで表す。ソフト間で持ち運べる。第9章

**ショットグレード** — カット単位の調整 / 作品全体の LMT とは別に、1カットずつ合わせる。第9章

**リフト / ガンマ / ゲイン** — 暗い所・中くらい・明るい所 / グレーディングでよく使う3つのつまみ。第9章

## HDR

**SDR (Standard Dynamic Range)** — 今までの映像 / 白いところが 100 nit くらいを想定して作られている。第10章

**HDR (High Dynamic Range)** — 明るいところがもっと明るい映像 / 1000 nit 以上を扱える。第10章

**nit (cd/m²)** — 明るさの単位 / 画面がどれくらい強く光るか。室内の紙は数十、スマホの白は 400〜1000、晴れた空は数千以上。第10章

**PQ (ST 2084)** — 絶対的な明るさで指定する方式 / 「ここは 500 nit」と決め打ちする。配信やディスクで使う。第10章

**HLG (Hybrid Log-Gamma)** — 従来テレビとも両立する方式 / 放送で使う。画面の明るさに合わせて伸び縮みする。第10章

**Rec.2100** — HDR の規格 / Rec.2020 の色域に PQ か HLG を組み合わせたもの。第10章

**1マスター多出力** — 1本作って何通りにも出す / ACES で作っておけば、出力変換を差し替えるだけで劇場用・SDR用・HDR用が出せる。第10章

## 合成・CG

**アルファ合成 (alpha compositing)** — 半透明の重ね合わせ / リニア空間でやらないと境界が汚くなる。第5章

**プリマルチプライ (premultiplied alpha)** — 色に透明度をかけてある状態 / 合成のときの標準的な持ち方。付録

**グロー / ブルーム** — 光のにじみ / 明るいところが周りにあふれる表現。リニアでないと不自然になる。第5章

**EXR (OpenEXR)** — 明るさを広く記録できる画像形式 / float で保存でき、1.0 を超える値も持てる。CG と合成の標準。第4章

**トーンカーブ** — 明るさの変換曲線 / 入力の明るさを出力の明るさに写す線。第3章

## そのほか

**ICC プロファイル** — 印刷や写真の世界の色管理 / OCIO とは別系統の仕組み。用途と考え方が違う。付録

**色度図 (chromaticity diagram)** — 色の地図 / 明るさを除いた「色み」だけを平面に並べた図。馬蹄形。第2章

**色覚多様性** — 色の見え方の個人差 / 色だけで情報を伝えないことが大切。第2章
