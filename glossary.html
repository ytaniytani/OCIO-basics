付録A

用語集

このサイトに出てくる言葉を集めました。全部に、やさしい言いかえを付けてあります。

色空間color space第2章

色の「単位」の決め方

数字にどんな色を割り当てるかの約束。原色の位置・白の色・数値と明るさの関係、の3点セット。

色域gamut第2章

使える色の広さ

その色空間で表現できる色の範囲。色度図の三角形の大きさ。

白色点white point第2章

「白」をどの色にするか

D65 は昼の空の光に近い白。

原色primaries第2章

混ぜるもとの3色

赤・緑・青をそれぞれどこに置くか。

伝達関数transfer function第3章

数字の曲げ方

光の量と保存する数値の対応ルール。

ガンマgamma第3章

数字の曲げ方の一種

いちばん単純な形の伝達関数。

リニアlinear第3章

まっすぐ

光の量と数値が比例している状態。

シーンリニアscene-referred linear第3章

光の量そのもの

現場にあった光の量に比例した数値。1.0 を超えてもよい。

ディスプレイ参照display-referred第3章

画面用に加工ずみ

画面に出すことを前提にした数値。ふつう 0〜1。

中間グレーmiddle grey第3章

まんなかの明るさ

光の量では 0.18 くらい。sRGB では 8bit で 118 前後。

ダイナミックレンジ第4章

明るさの守備範囲

一番暗いところと一番明るいところの幅。

白飛びclipping第4章

真っ白でつぶれる

記録できる上限を超えて情報が消えること。もどらない。

ビット深度bit depth第4章

数字のこまかさ

8bit なら256段階、10bit なら1024段階。

float浮動小数点第4章

小数で持つ

1.0 を超える明るさも記録できる。

sRGB第2章

パソコンやスマホの標準

いちばん普及している表示用の色空間。

Rec.709第2章

テレビの標準

sRGB とほぼ同じ色域。伝達関数の扱いが少し違う。

Display P3第2章

少し広い

最近のスマホやMacの画面。赤と緑が sRGB より濃く出せる。

Rec.2020第2章

かなり広い

4K/8K放送や HDR で使う。

ACES2065-1AP0第8章

保存と受け渡し用

ACES のいちばん広い色空間。人の目に見えない色まで含む。

ACEScgAP1第8章

CGと合成の作業用

リニアで扱いやすい。ACES で作業するときの主役。

ACEScc / ACEScct第8章

色を調整するとき用

対数のカーブ。ACEScct は暗いところの操作感が従来機に近い。

Log第6章

眠い灰色に見えるやつ

広い明るさを少ないビットに詰め込む記録方式。カメラごとに種類がある。

OpenColorIOOCIO第6章

色の翻訳係

どの色空間からどの色空間へどう変換するかをまとめて、いろんなソフトに同じ答えを出させる仕組み。

config.ocio第7章

変換のルールブック

OCIO の設定を書いた1つの YAML ファイル。

colorspaces第7章

色空間の一覧

config でどんな色空間を扱うかの定義。

roles第7章

役割の割りあて

「作業用はこれ」「表示用はこれ」と名前で決めておく仕組み。ソフトはこの名前で色空間を探す。

displays / views第7章

表示先と見え方

どの画面に、どの見た目で出すかの組み合わせ。

looks第9章

味付けの登録

config に書いておける調整。第7章・

環境変数 OCIO第7章

どの config を使うかの指定

パソコンにパスを設定すると、対応ソフトがそろってその config を使う。

LUTLook-Up Table付録

変換の早見表

計算のかわりに表を引いて色を変える方法。`.cube` などのファイル。

ACES第8章

映画業界の共通ルール

Academy Color Encoding System。どのカメラの絵も同じ場所に集めて作業するやり方。

入力変換Input Transform / IDT第8章

素材を共通の場所に翻訳

カメラごとの絵を ACES の座標に持ってくる。

出力変換Output Transform第8章

見る機械に合わせて刷る

ACES のデータを、その画面で正しく見える形に変換する。ACES 1.x では RRT と ODT の2段だった。ACES 2.0 では1つにまとまった。

RRTReference Rendering Transform第8章

共通の見た目づくり(ACES 1.x)

どの出力にも共通でかかる仕上げ。

ODTOutput Device Transform第8章

出力機器ごとの調整(ACES 1.x)

RRT のあとで、画面ごとの違いを合わせる。

LMTLook Modification Transform第9章

作品全体の味付け

出力変換の前に入れる。

トーンマッピングtone mapping第8章

広い明るさを画面に押し込む

明るすぎる部分をなだらかに丸めて表示できる形にする。

カラーグレーディング第9章

色の味付け

明るさと色みを整えて作品の雰囲気を作る作業。

カラーコレクション第9章

色をそろえる

カットごとのばらつきを合わせる作業。グレーディングの前段。

CDLASC CDL第9章

調整のかんたんな共通形式

slope・offset・power・saturation の4つで表す。ソフト間で持ち運べる。

ショットグレード第9章

カット単位の調整

作品全体の LMT とは別に、1カットずつ合わせる。

リフト / ガンマ / ゲイン第9章

暗い所・中くらい・明るい所

グレーディングでよく使う3つのつまみ。

SDRStandard Dynamic Range第10章

今までの映像

白いところが 100 nit くらいを想定して作られている。

HDRHigh Dynamic Range第10章

明るいところがもっと明るい映像

1000 nit 以上を扱える。

nitcd/m²第10章

明るさの単位

画面がどれくらい強く光るか。室内の紙は数十、スマホの白は 400〜1000、晴れた空は数千以上。

PQST 2084第10章

絶対的な明るさで指定する方式

「ここは 500 nit」と決め打ちする。配信やディスクで使う。

HLGHybrid Log-Gamma第10章

従来テレビとも両立する方式

放送で使う。画面の明るさに合わせて伸び縮みする。

Rec.2100第10章

HDR の規格

Rec.2020 の色域に PQ か HLG を組み合わせたもの。

1マスター多出力第10章

1本作って何通りにも出す

ACES で作っておけば、出力変換を差し替えるだけで劇場用・SDR用・HDR用が出せる。

アルファ合成alpha compositing第5章

半透明の重ね合わせ

リニア空間でやらないと境界が汚くなる。

プリマルチプライpremultiplied alpha付録

色に透明度をかけてある状態

合成のときの標準的な持ち方。

グロー / ブルーム第5章

光のにじみ

明るいところが周りにあふれる表現。リニアでないと不自然になる。

EXROpenEXR第4章

明るさを広く記録できる画像形式

float で保存でき、1.0 を超える値も持てる。CG と合成の標準。

トーンカーブ第3章

明るさの変換曲線

入力の明るさを出力の明るさに写す線。

ICC プロファイル付録

印刷や写真の世界の色管理

OCIO とは別系統の仕組み。用途と考え方が違う。

色度図chromaticity diagram第2章

色の地図

明るさを除いた「色み」だけを平面に並べた図。馬蹄形。

色覚多様性第2章

色の見え方の個人差

色だけで情報を伝えないことが大切。
