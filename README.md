# OCIO-basics

映像やCGの知識がない中学生向けに、**OCIO (OpenColorIO)** と **ACES** をさわって学べる Web ページを作るプロジェクト。

「読んで覚える」ではなく、**色がズレる事故を自分で起こして、自分で直せるようになる**ことを目標にしています。

## いまの状態

仕様策定フェーズ (P0)。実装はまだありません。

## 扱う範囲

全11章。基礎から順に積み上げます。

1. 色ってなんだろう(光・目・数字)
2. 数字だけでは色は決まらない(色空間)
3. 明るさの数字は正直じゃない(リニアとガンマ)
4. 見える範囲がちがう(ダイナミックレンジ)
5. 混ぜると壊れる(なぜリニアで計算するのか)
6. OCIO の登場(素材バラバラ問題を直す)
7. `config.ocio` をさわる(設定ファイル実習)
8. ACES というみんなのルール
9. カラーグレーディングはどこに入れる
10. HDR — 明るいテレビにも届ける
11. まとめとチェックテスト

## 方針

- ビルド不要の静的サイト。HTML + CSS + JavaScript のみ。外部 CDN もフレームワークも使わない

- 外部への通信ゼロ。アクセス解析もクッキーも使わない
